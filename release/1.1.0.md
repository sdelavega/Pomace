# Pomace 1.1.0

This is the last update you need to install by hand: Pomace now updates itself.

- Install Pomace by opening the disk image and dragging Pomace to Applications.
- Pomace includes its compression tool, so Homebrew is no longer required.
- The app and bundled compressor support Apple silicon and Intel Macs running macOS 14 or later.
- Automatic update checks and Check for Updates are available in Pomace.
- A custom compressor can still be selected in Advanced settings and is checked before each run.

# Pomace 1.0.2

This update improves compression progress, stopping a run, and switching between folders.

- Fixed a subprocess deadlock that could occur when the compressor filled its error-output pipe.
- Stop now acknowledges the request, lets the active batch finish safely, and reports the final outcome. No further batches start after the request is observed at a batch boundary.
- Fixed reclaimed-space accounting when a run stops before processing all files.
- Switching folders can reuse scans completed within the last minute. Reused scans are labelled; Rescan always refreshes them. Compression and decompression invalidate affected cached results.
- Progress identifies the start of the active batch. Diagnostic logs include batch timing, process exit status, and stop requests.

Compression remains verified. Stop does not interrupt the compressor mid-file. An independently hung compressor can still prevent the active batch from finishing; the exact hang reported in issue #1 has not been reproduced.

Localization and alternative installation guidance remain follow-up work.

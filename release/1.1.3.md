# Pomace 1.1.3

Pomace fixes a 1.1.2 regression that made Compress look dead on very large folders.

- Compressing a folder whose scan was capped at 200,000 displayed rows now shows a visible "Preparing the full file list…" indicator while the complete target list is gathered, instead of appearing to do nothing.
- Compress and Decompress are disabled while that list is prepared, in both the window and the menu bar, so a second press can no longer be swallowed silently.
- Switching folders while the list is prepared now explains itself instead of silently dropping the run.

Supports Apple silicon and Intel Macs running macOS 14 or later.

# Pomace 1.1.4

Pomace fixes history and reporting correctness issues found after 1.1.3.

- Removing a folder while "Check All Folders" runs no longer resurrects its deleted history: the check is cancelled by removal and by any rescan, and it never records a folder that is no longer watched.
- Snapshots taken by the folder check no longer land mid-run, so a decompression is no longer misreported as re-expansion and no longer suggests a schedule change nobody asked for.
- A compression baseline can no longer be recorded from a scan that was already in flight when the compression finished, which used to skew the degradation figure until the next full compression.
- A cancelled sweep is recorded as cancelled, so it no longer advances the incremental cutoff past files the walk never reached.
- A interrupted database migration now fails loudly instead of silently leaving the app with an empty folder list forever.
- The mutation log is reopened per line, so rotation by the sweep agent can no longer leave a long-running app writing to a deleted file.
- Savings-estimate basis, run progress after a failed batch, exclusion matching above the folder root, and sweep-agent error logging are also corrected.

Supports Apple silicon and Intel Macs running macOS 14 or later.

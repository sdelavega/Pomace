# Pomace 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pomace 1.1: a bundled universal applesauce with a custom override, a universal
app, Sparkle updates, a Tesserae-style DMG/appcast/cask pipeline, eight locales, an
accessibility pass, and Help → Report a Problem.

**Architecture:** This keeps ADR-0013. SwiftPM builds the code and `build-app.sh` assembles
and signs the bundle. A separately locked Cargo wrapper crate builds the helper.
PomaceCore stops producing user-facing prose: it returns typed values, and PomaceApp turns
them into catalog strings.

**Tech Stack:** Swift 6 / SwiftUI / Swift Testing, SwiftPM, Sparkle 2.10.0, Rust (stable,
`--locked`) for the helper, bash and python3 for scripts.

**Spec:** `docs/superpowers/specs/2026-10-22-pomace-1.1-design.md`. Read it before any task.

## Global Constraints

- Deployment floor macOS 14 (`MACOSX_DEPLOYMENT_TARGET=14.0`, `platforms: [.macOS(.v14)]`). Release builds are universal `arm64` + `x86_64`.
- The bundle ID stays `com.sdelavega.Pomace`. The LaunchAgent label and plist name are unchanged.
- Every applesauce compress argv contains `--verify`. Never remove the assertion tests for it.
- No compressor runs unless it passed the capability check (`ToolCapabilities.isUsable`) in the same resolution. Re-resolve before every run; never reuse a cached check.
- Helper pin: applesauce crate `=0.8.10`, in a wrapper crate copied from `~/src/tesserae/tools/applesauce` and renamed `pomace-applesauce`, with all dependency pins kept exact.
- Sparkle pin: `https://github.com/sparkle-project/Sparkle`, exact version `2.10.0` (revision `eef1a539a373c1f1a320624b1130fc5de7b2e100`). Pin the Sparkle tool SHA-256s in `release/sparkle-tools.sha256`.
- Sign inside-out and never pass `codesign --deep`.
- Locales: `en` (source), `zh-Hans`, `es`, `ja`, `ko`, `de`, `fr`, `pt-BR`. Translations are machine-made and say so.
- `CompressionMode` raw values and any enum raw value written to SQLite or UserDefaults are persistence keys. Never change them. Display text is separate.
- Log messages (`MutationLog`, `Logger`) stay English and unlocalized.
- Tests use Swift Testing (`import Testing`, `@Test`, `#expect`) like the existing suites.
- Never print or log the environment. Never commit secrets, keychain contents, Apple IDs, team IDs or `/Users/<name>` paths.
- Never write outside the worktree, `build/`, `dist/`, temp dirs and disposable sparse images. Never write to `/Volumes/*` except a sparse image the test itself created.
- No network publishing in any task: no push, tag, `gh release`, gh-pages or tap writes. `release/publish.sh` is written and tested against fakes only.
- New docs and scripts that carry a licence notice use "Copyright (C) 2026 Stephen de la Vega", never "All rights reserved".
- Each task ends with `scripts/gate.sh` passing (from Task 1 onwards) and one commit whose message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A custom compressor that changes after it is chosen.** If it is deleted, replaced by a script without `--verify`, or symlinked to `/bin/sh`, the next run must re-check it, fall back to the bundled copy, and show why. It must never run unchecked. The pinning test is in Task 2.
2. **An update arriving mid-compression.** This covers the in-app run and the headless `--sweep-all` agent, which is a separate process. Relaunch is postponed until the run ends, and a batch is never killed. The pinning test is in Task 5 (`SweepLock`).
3. **History written by 1.0.2.** After the strings refactor, SQLite rows holding mode, deferral, and reason codes from 1.0.2 must still decode and display. The pinning test is in Task 7 (a fixture DB).
4. **Redaction misses.** Report text can contain paths with spaces or Unicode, `/Volumes/<name>`, `/private/var/folders/...`, a bare username or host name, or paths inside `.ips` JSON. All of them must be redacted. The pinning test is in Task 11.
5. **Localized interpolation.** Plurals (`1 file` / `2 files`, and languages without plurals) and format specifiers must match per locale. A mismatch must fail the gate rather than garble or crash at runtime. The pinning test is in Task 9.
